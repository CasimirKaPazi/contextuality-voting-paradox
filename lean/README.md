# Formal proofs

Lean 4 files that check statements from the notes and the drafts. They form one Lake project with Mathlib as dependency: run `lake build` in `lean/` (toolchain in `lean/lean-toolchain`). The older files use only core Lean; `ProbLine.lean`, `CircleTournaments.lean`, `LoopsOfRelations.lean`, `ProbabilisticArrow.lean`, `PathPinning.lean`, `ArrowGeneral.lean`, `ArrowBase.lean`, `JointDraws.lean`, `Scenarios.lean`, `Rankings.lean`, `GSScenario.lean`, `JoinLotteries.lean`, `Isotropy.lean`, `SummaryAutomaton.lean`, `GSTopTwo.lean`, `GSCorollary.lean`, `CoreDraw.lean`, `StrategicInformation.lean`, `MemoryWalk.lean`, `TwoPlayer.lean`, `TightCounterexample.lean`, `ThreeOutcomes.lean`, `ApprovalVeto.lean`, `CallGame.lean`, `GlobalFormLottery.lean`, `ContextualFraction.lean`, `ContextualBridge.lean`, `RealDegreeBridge.lean`, `RealDegreeWinding.lean`, `LocalPareto.lean`, `SPDegree.lean`, `ConsistencyCertificates.lean`, `TotallyTight.lean`, `StrategicCount.lean`, `Certification.lean`, `OppositeVoters.lean`, `EqualityCriterion.lean`, `Covers.lean`, `ArrowScenario.lean`, `Couplings.lean`, `GlobalForm.lean`, `GlobalFormSP.lean`, `ConsistencyScenario.lean`, `GlobalFormReal.lean`, `CoversDecomp.lean`, `GameTree.lean`, `EqualityVA.lean`, `LeaderRank.lean`, `Revelation.lean`, `Intensity.lean`, `Honest.lean` and `BallotPolytope.lean` use Mathlib. Finite statements are proved by computation (`decide`); the others by ordinary proofs. Every file is a module in Lean's module system: it begins with `module`, imports with `public import`, and puts its content in `@[expose] public section`, so that definitions stay unfoldable in the files that import it, as before.

Each file's header names the statements it checks. This file is the index of what is checked formally. The notes and drafts cite the files at the statements they check, and the last column lists where these citations are.
